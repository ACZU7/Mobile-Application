# Meeting notes

Keep one short Markdown note for each group meeting. Use the date-first naming convention:

`YYYY-MM-DD-meeting-XX.md`

Each note should record attendees, decisions, actions, due dates and risks. Update `../../contributions.md` after completing work so meeting decisions can be traced to commits and evidence.

Use [meeting-template.md](meeting-template.md) as the starting point for each new note.
